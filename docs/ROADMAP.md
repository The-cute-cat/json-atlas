# JSON Atlas 开发路线

## 0.1：桌面原型

接入现有阅读器，分离页面、样式与脚本，建立可复现的前端和桌面构建流程。

## 下一步

已接入原生文件选择、完整路径文档身份、系统文件关联与单实例传参、主显示器工作区 75% 的启动尺寸、桌面启动页与独立文档图标、Worker 解析、分支分页和不依赖 DOM 的可取消搜索；桌面文件恢复记录改为路径列表。已加入纯数据与原生路径读取的回归测试。

1. 按 [README 的发布前验收](../README.md#发布前验收)验证 WebView2、安装后的文件关联、中文长文本、模板、复制、重启恢复和多显示器窗口行为。
2. 将模板与会话状态从 DOM 逻辑继续分离，补充原生事件和交互回归测试。
3. 支持最近文件、外部变化提示和数组条目的精确会话恢复。
4. JSONL 行偏移索引、按需加载，进一步降低全文读取和完整解析的内存开销。
5. 验证导图可见节点渲染、内存和响应时间，再公布实测规模。

## 测试样本

先使用 examples/ 内的两个文件。之后覆盖坏行、空文件、深层嵌套、超长文本、同名同大小不同目录文件与真实大文件。
