# JSON Atlas 开发路线

## 0.1：桌面原型

接入现有阅读器，分离页面、样式与脚本，建立可复现的前端和桌面构建流程。

## 下一步

1. 在真实 WebView2 窗口验证打开/拖入文件、中文长文本、搜索、模板、复制、设置导入导出、重启恢复。
2. 将解析、路径、模板从 DOM 逻辑分离，补充有代表性的测试。
3. 建立原生文档身份与路径会话恢复，支持最近文件和变化提示。
4. JSONL 行偏移索引、按需加载、可取消后台搜索；搜索不依赖 DOM。
5. 验证导图可见节点渲染、内存和响应时间，再公布实测规模。

## 测试样本

先使用 examples/ 内的两个文件。之后覆盖坏行、空文件、深层嵌套、超长文本、同名同大小不同目录文件与真实大文件。

## 发布前

项目名称为 JSON Atlas，仓库与包名为 json-atlas，应用标识为 io.hopecat.jsonatlas。发布前确认图标与许可证；完善贡献说明及发布流程。当前没有创建远程仓库或发布安装包。
