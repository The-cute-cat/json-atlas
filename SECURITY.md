# Security policy

Report suspected vulnerabilities by email or through GitHub if the private form is available. Keep vulnerability details and affected files in the private report. [security@hopecat.dpdns.org](mailto:security@hopecat.dpdns.org) · [GitHub private vulnerability reporting](https://github.com/The-cute-cat/json-atlas/security/advisories/new)

**Scope of this address.** This email address is provided exclusively for security vulnerability reporting and responsible disclosure. Unsolicited marketing, commercial outreach, automated promotional messages, recruitment offers, and other non-security-related communications are not permitted and will be discarded without a reply.

In a private report, include the JSON Atlas version and edition, operating system, affected feature, expected impact, and steps to reproduce. A minimal synthetic sample helps the maintainer verify the report. Keep credentials, personal data, and original private files out of attachments.

Use the [bug report form](https://github.com/The-cute-cat/json-atlas/issues/new?template=bug_report.yml) for ordinary bugs.

**用途说明。** 该邮箱仅用于安全漏洞报告与负责任披露。未经请求的营销、商业推广、自动化群发、招聘邀约及其他与安全无关的邮件不在受理范围内，将不予回复并直接删除。

私密报告请附应用版本和类型、操作系统、受影响的功能、可能的影响及复现步骤。若需要附样本，请使用最小的合成数据。普通故障请使用 [Bug 报告表单](https://github.com/The-cute-cat/json-atlas/issues/new?template=bug_report.yml)。
