阅读、查找与编辑

逐层阅读对象与数组

在画布上平移、缩放和展开节点，也能读取字符串中嵌入的 JSON。隐藏规则可在设置中按文件名或路径搜索，也能在当前画布中临时屏蔽匹配的规则。

按键名或值查找

搜索键名或值，支持大小写、全词和常用正则。可限定到选中分支，命中后定位到节点并查看路径。

设计结构，编辑原文

新建空白 JSON，或对符合大小限制的 JSON 启用设计模式，在画布中添加、重命名或删除主题。IDE 支持高亮、折叠和格式化。当前开发版提供重做及最多 50 步撤销。

按页阅读大文件，按需载入标签

在「设置 → 性能与内存」调整大文件阈值、索引重建方式和后台文件释放策略。

桌面磁盘索引

超过阈值时切换到只读树形视图，磁盘索引每页读取 100 项。智能重建可复用已有索引，并在内容显示后校验文件。

恢复上次的阅读位置

启用会话恢复后，可找回每个文件的展开状态、视图位置和 IDE 光标。小内存模式启动时只载入上次活动的文件，其余标签选中时再载入。

释放后台文件

可按闲置时间、载入数量上限或手动操作释放后台文件，保留标签和阅读位置。正在阅读、有未保存修改或撤销记录的文件会保留。

使用前了解

几个你可能关心的问题。

文件会传到服务器吗？

应用在本机解析、搜索和编辑文件，不提供文件上传或云同步。在线版首次打开需要从站点加载程序和图片；保存后的单文件 HTML 可以离线运行。

支持 JSONL 和有问题的行吗？

支持 .jsonl、.ndjson 和 .jsonlines。默认跳过无法解析的行，也可在设置中启用严格模式。如果跳过了坏行，请用「另存为」保留原始文件。

能编辑多大的文件？

树形编辑和 IDE 面向以内存方式载入的文件。设计模式适用于小于设定上限的 JSON，默认 8 MiB，最高可设为 32 MiB。磁盘索引模式提供只读树形视图。

未保存的设计能恢复吗？

设计中的未保存修改会在本机暂存，重启时可以恢复。保存或确认放弃修改后，应用会移除对应草稿。

遇到问题，怎样提供有效反馈？

请在 GitHub Issues 提供应用版本、系统、操作步骤和脱敏后的最小样例。也欢迎分享你实际使用的场景，或通过 Pull Request 改进文档与代码。
