对象与数组以卡片呈现，支持平移、缩放和字段隐藏。字符串中的内嵌 JSON 也可以展开阅读。

02 / 查找

搜索键名或值，支持大小写、全词和常用正则。可限定到选中分支，命中后定位到节点并查看路径。

使用前了解

几个你可能关心的问题。

文件会传到服务器吗？

应用在本机解析、搜索和编辑文件，不提供文件上传或云同步。在线版首次打开需要从站点加载程序和图片；保存后的单文件 HTML 可以离线运行。

支持 JSONL 和有问题的行吗？

支持 .jsonl、.ndjson 和 .jsonlines。JSONL 加载会记录并跳过无法解析的行；如果跳过了坏行，保存时请使用“另存为”，保留原始记录。请先用副本验证自己的数据。

能编辑多大的文件？

编辑功能面向内存模式的小文件。桌面磁盘索引模式保持只读；IDE 视图另有字符数、行数与结构复杂度限制，超出后会回退到树形视图。具体限制见 使用说明。

遇到问题，怎样提供有效反馈？

请在 GitHub Issues 提供应用版本、系统、操作步骤和脱敏后的最小样例。也欢迎分享你实际使用的场景，或通过 Pull Request 改进文档与代码。
