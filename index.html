    设置
    设置自动保存在本机，视图和文件处理设置在关闭面板后应用

    外观与视图

    界面外观

    白天模式适合明亮环境，夜间模式减少暗处的屏幕亮度。默认跟随系统，系统切换外观时会自动更新。
    调整左侧已打开文件的展示方式。将鼠标移到栏上可查看文件名，并切换到对应文件。

    文档视图

    小文件可使用带行号和语法高亮的 IDE 视图，支持编辑、折叠与格式化。较大或复杂文件自动使用树形视图，两种视图共享修改内容。
    默认只在鼠标移到行号区域或用键盘聚焦按钮时显示；开启后始终显示。切换和悬停均无动画。

    树形阅读

    布局与展开

    开启后，子树在父节点右侧展开；关闭后，子树从父节点下方向右缩进。切换不会收起已展开的节点。
    未恢复阅读状态、也未应用展开模板时，按所选层数展开。数组仅展开第一项，避免一次显示过多内容。
    默认关闭。关闭仅隐藏描边，点击选中节点后仍可按 Ctrl/⌘+C 复制内容。
    选择数组条目显示为 0、1、2… 或 1、2、3…。仅改变阅读编号，路径中的真实下标仍从 0 开始。

    字段显示

    将过长的字段内容限制在指定行数内，让树形结构更紧凑。超出部分可点击卡片上的 … 查看全文。
    开启“限制内容高度”后生效，只影响卡片显示，不会截断复制的内容。

    文件与恢复

    JSONL

    多条 JSONL 记录放在同一个数组根节点下，便于逐条浏览；关闭后只显示第一条记录。
    任意记录行解析失败或包含注释时，拒绝预览整个文件。关闭后跳过这些行；空行始终忽略。

    启动与会话

    下次启动时继续打开本次的文件；关闭此项会清除已保存的恢复记录。
    需先开启“重启时重新打开文件”。恢复文档视图、树形阅读位置，以及 IDE 的光标、折叠、滚动位置和字号。

    性能与内存

    当前状态

    文件载入
    索引子页缓存
    用量仅估算前端保留的索引子页。该预算由所有索引文件共享。

    内存管理

    离开文件达到指定时间后释放解析数据和索引缓存。再次选中标签会重新载入。保留正在阅读、有未保存修改或可撤销操作的文件。
    超过上限时优先释放最久未阅读的文件。当前文件和有编辑记录的文件保留，因此载入数量可能暂时超过上限。
    启用「文件与恢复 → 重启时重新打开文件」后，启动时只载入上次活动的文件。其余标签在选中时载入。

    大文件

    打开文件时，阈值以内使用内存解析，超过阈值时桌面版使用磁盘索引，浏览器预览会拒绝打开。调整后，下次打开文件会按新阈值选择读取方式。1 MB = 1024 × 1024 字节。
    桌面版。智能重建可复用已保存的索引，并在显示内容后校验哈希。文件大小变更或缺少已保存的哈希时会重建。

    模板与备份

    结构模板

    结构模板
    记录常用的展开层级，并管理隐藏的节点。隐藏规则按结构匹配所有文件，数组元素共用同一路径规则。
    未记录
    打开文件时按已记录的模板展开，适合连续阅读结构相似的文件。恢复阅读状态时，优先使用上次的展开状态。

      没有匹配的文件或规则。

      设置备份

      设置导入 / 导出
      导出应用版本、阅读设置和结构模板。隐藏规则的来源只记录文件名。导入后替换对应设置。

      编辑与设计

      设计模式

      在设计模式的画布左下角显示主题操作。
      应用于设计模式的树形画布。根节点和数组元素可通过「编辑值」修改内容。
      只有小于该上限的 JSON 文档可以进入设计模式。单位为 MB，默认 8，最高 32。

      IDE 编辑

      默认开启，按文本长度、行数和结构复杂度限制 IDE 的使用。关闭后，阈值以内的复杂文件也可使用 IDE；超过大文件阈值的文件仅支持树形视图。

      键盘与菜单

      键盘操作
