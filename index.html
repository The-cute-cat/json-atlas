路径：$ 空白处拖动 · 滚轮平移 · Ctrl/⌘ + 滚轮缩放 · 右键节点展开/收起子树
设置
设置自动保存在本机，关闭面板即可继续阅读
阅读与布局
开启后，子树在父节点右侧展开；关闭后，子树从父节点下方向右缩进。切换不会收起已展开的节点。
自动应用结构模板
打开文件时按已记录的模板展开，适合连续阅读结构相似的文件。恢复阅读状态时，优先使用上次的展开状态。
默认展开层数
未恢复阅读状态、也未应用展开模板时，按所选层数展开。数组仅展开第一项，避免一次显示过多内容。
数组编号起点
选择数组条目显示为 0、1、2… 或 1、2、3…。仅改变阅读编号，路径中的真实下标仍从 0 开始。
多文件栏样式
调整左侧已打开文件的展示方式。将鼠标移到栏上可查看文件名，并切换到对应文件。
重启时重新打开文件
下次启动时继续打开本次的文件；关闭此项会清除已保存的恢复记录。
恢复阅读状态
需先开启“重启时重新打开文件”。恢复上次的平移位置、缩放比例和展开层级，继续之前的阅读。
字段内容
限制内容高度
将过长的字段内容限制在指定行数内，让树形结构更紧凑。超出部分可点击卡片上的 … 查看全文。
最多显示行数
开启“限制内容高度”后生效，只影响卡片显示，不会截断复制的内容。
JSONL
以数组显示多条记录
多条 JSONL 记录放在同一个数组根节点下，便于逐条浏览；关闭后只显示第一条记录。
严格模式
任意记录行解析失败或包含注释时，拒绝预览整个文件。关闭后跳过这些行；空行始终忽略。
模板与备份
结构模板
记录常用的展开层级，也可通过模板编辑器隐藏字段。“立即应用”用于当前文件，“清除”会恢复隐藏字段。
未记录
设置导入 / 导出
导出阅读设置和结构模板，便于备份或迁移到另一台电脑。导入后替换对应设置，不包含已打开的数据文件。
